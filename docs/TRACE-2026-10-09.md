# Trace 2026-10-09: the phone app, 11 minutes of many operations

Source: a PacketLogger trace of the iOS Cortex Cloud app driving Anup's Nano Cortex (NanOS 2.2.1), 2026-10-09,
scrubbed to the ATT values on C304 (writes) and C305 (notifies), pedal serial masked with `X`. The recording itself
is not published (recorded phone-app session, kept off the repository for privacy); the frames quoted here carry no
identifying data.

The same note lives in both repos (`nano-cortex-editor/docs/` and `nano-cortex-editor-mac/docs/`).

How to read this note:

- **Times** are seconds from the first packet of the fixture (the first `tx` event, absolute `t = 540406.361`).
  They match the leader's `lots-timeline.txt`. 895 typed messages, 0.0 → 662.3 s.
- **Frames** are `[len = frame.length − 2] C0 [protobuf payload] [u32 LE message type]` (multi-chunk messages use the
  continuation flags in byte 1; see `INVESTIGATION.md` §3 / `PROTOCOL-NOTES.md`). Example hex is the exact ATT
  value from the fixture, single-chunk frames only.
- **Fields** are written `{field: value}`; `-1` is a sign-extended 10-byte varint (`FF FF FF FF FF FF FF FF FF 01`).
  Protobuf drops zero values, so "absent" usually means 0.
- **Preset indices are 0-based** on the wire; "preset N" in prose is index + 1 where it matters.
- **Confidence**: *confirmed* = the bytes and the pedal's reaction both show it in this trace (or another source
  agrees byte for byte); *inferred* = consistent with the data but not proven; *unknown* = seen, not understood.
  Everything inferred is marked **unverified**.
